# Project Rules & Guidelines

## Playwright MCP & Browser Tools
- Playwright MCP tools (browser_navigate, browser_take_screenshot, etc.) are executed strictly via the built-in IDE MCP server interface.
- Do NOT install local `playwright` npm packages or create local Node Playwright scripts in the workspace.
- Any temporary log or YAML outputs generated by Playwright MCP in `.playwright-mcp/` are temporary and must not be committed.
- Keep the workspace clean: only production static HTML, CSS, assets, and project customization files (`.agents/`, `GEMINI.md`, `.gitignore`) should reside in the repository.
