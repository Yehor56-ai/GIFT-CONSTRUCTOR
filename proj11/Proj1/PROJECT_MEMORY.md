# Project Memory — Gift Constructor (Конструктор подарунків)

## Overview
Minimalist single-page gift constructor web application designed for quick gift recommendations based on recipient, occasion, and budget.

## Core States
1. **Empty State (Пустий екран)**: Initial state with default unselected dropdowns and a placeholder result box ("Подарунок не зібрано").
2. **Filled Form State (Заповнена форма)**: User selects recipient, occasion, and inputs budget.
3. **Error State (Помилка)**: Displays error alert banner and highlights invalid fields if user attempts submit with empty fields.
4. **Result State (Результат)**: Displays a single calculated gift recommendation card with recipient & occasion badge, title, description, image, and price.

## Strict Exclusions
- NO Payment / Checkout
- NO Catalog browsing
- NO User registration / Auth
- NO Saving / History
- NO Auto-selection on page load
